Quick orientation for a new contributor:

1. Read `src/lib/score.ts` — the nine pillars and their weights.
2. Read `src/lib/methodology/registry.ts` — the 26 factors, equations, variables, sources.
3. Read `src/components/methodology/pillar-calculation.tsx` — how a score becomes a
   plain-English, cited, verifiable explanation on screen.
4. Everything else is presentation around those three files.
